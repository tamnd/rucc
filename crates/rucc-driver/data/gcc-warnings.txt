# Every -W name gcc 16 knows, one to a line and sorted bytewise. src/warnings.rs reads this to decide whether a -W flag is one gcc would accept.
#
# The names are what this prints with gcc 16.2:
#
#   for class in warnings common c c++ objc objc++ fortran d modula-2 undocumented; do gcc --help=$class; done | perl -ne 'print "$1\n" if /^  -W([A-Za-z0-9+_.-]+?)(?:=|<|\s|$)/' | LC_ALL=C sort -u
#
# The other languages' names are here because gcc accepts them on a C compile with a warning and a zero exit status. The command also prints larger-than-, which is -Wlarger-than- followed by a number, and that one is left out because the code takes it by its prefix. A gcc built for Darwin prints nonportable-cfstrings and experimental-fmv-target as well, which a Linux gcc does not know, and a gcc built without the D or Modula-2 front end is missing speculative and case-enum. To move to a newer gcc, run the command with it and replace the names below.
